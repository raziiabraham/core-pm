# Artifact template · Intervention contract

The tutor fills this in with the learner, using only observations the learner
has actually made, with dates. Never invent an instance, a quote, or a third
party's opinion of the person. Where the learner is working from impression
rather than a recorded observation, write `<unknown>` and carry it into the Gaps
section — an intervention built on remembered impressions is the failure this
lesson is about.

Write this document to be handed to the person it concerns. That constraint does
most of the quality work by itself.

Delete the guidance in parentheses in the finished artifact.

```markdown
# Intervention contract · <person or role> · <decision class>

- **Date:** <YYYY-MM-DD>
- **Decision class affected:** <one class, named>
- **Current authority level (LD-02):** <1-5>
- **Level during this intervention:** <1-5>
- **Rung on the ladder:** <1-6> — <name it out loud in the conversation too>

## Structural test — run this before anything else

> Would a capable person in this seat, with this direction, these decision
> rights, this operating system, this evidence, and these interfaces, have hit
> the same wall?

- **Answer:** <yes / no>
- **Weakest of the four:** <direction (LD-01) / rights (LD-02) / operating system
  (LD-04) / capability and interfaces (LD-05)>
- **If yes:** <what I am fixing instead of intervening — and this contract stops
  here>

## Failure mode

<An observable pattern, with instances. Not a trait, not a standard, not other
people's feelings.>

| # | What I observed | Date | Where I observed it |
|---|---|---|---|
| 1 | <…> | <…> | <the artifact, meeting, or decision> |
| 2 | <…> | <…> | <…> |
| 3 | <…> | <…> | <…> |

- **Pattern or single instance?** <three of the same shape is a pattern; one is
  data. Say which you have.>
- **Responding to reasoning or to outcome?** <reasoning / outcome> — <if outcome
  with sound reasoning, say what that changes, and consider whether the
  intervention belongs on the system instead>

## Scope

| Decisions that move to me | Decisions that explicitly stay with them |
|---|---|
| <…> | <name them — unstated scope expands> |

- **Why this rung and not the one below:** <the rung below is insufficient
  because …>
- **If I chose rung 5, the honest reason:** <the failure mode / the clock — these
  are different reasons and only one is about this person>

## Exit

- **Observable that returns ownership:** <something they can watch themselves>
- **Checked on:** <YYYY-MM-DD — arrives whether or not anyone raises it>
- **Who decides the return:** <person>
- **Where the return is announced:** <the same audience that saw the
  intervention. A public intervention with a private return is not a return.>

## Support attached

<Not encouragement. A specific information gap I will close, an interface I will
open, or a decision they keep in order to practise.>

- <…>

## What I will say

- **Opening sentence, verbatim:** "<…>"
- **Check:** <does this sentence name a change in decision rights? Any version
  that starts "let me just help with" and does not name the change is a silent
  takeover.>

## If the exit condition is not met

- **The honest options:** <return anyway with a revised standard / the class does
  not return and we have the role conversation>
- **What I will not do:** <extend a second time. An intervention that keeps
  getting extended is a decision I am avoiding.>
- **Sentence I would say if the answer is a role change:** "<…>"

## Gaps

<Everything marked `<unknown>` above, including any instance you believe
happened but cannot date or locate.>
```

## Quality bar

Before saving, check all six exposures are present. Name any that are missing
rather than filling them in yourself:

| Exposure | Present when |
|---|---|
| Choice | One rung is named, with a reason the rung below is insufficient |
| Evidence | Every instance has a date and a place it was observed; impressions read `<unknown>` |
| Uncertainty | The contract says whether this is a pattern or a single instance, and whether it responds to reasoning or outcome |
| Alternatives | The structural test was run and its answer recorded, including what would be fixed instead |
| Owner | Scope names both what moves and what stays; the return decider is named |
| Revision trigger | The exit has an observable the person can watch, a date, and a public announcement channel |

One further test specific to this artifact: hand it to the person it concerns.
If you would not, the failure mode is a trait, the scope is vague, or the exit
does not exist.

Tell the learner they can stress-test this with `review-artifact`.
