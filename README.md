# CORE / PM

The complete course site for CORE / PM: four cumulative sessions, a pre-course Noted briefing, pre-readings, live decks, protected facilitator run sheets, and Week 5 Demo Day context.

1. Choose what deserves PM attention.
2. Form a product view worth trusting.
3. Earn the problem definition.

Each unit includes a Noted decision prompt and source/further-reading notes. The course and *PM Is Now Another Member of Technical Staff* are independent: the course re-owns core Product Management practice, while the book explores deeper specialist-domain involvement.

The dedicated `/noted` pre-course briefing is an 18–22 minute orientation before Session 1. It covers the product thesis, end-to-end journey, live and planned capabilities, technical boundaries, constructed case populations and team, initial signals, evidence provenance, recurring vocabulary, and a guided product walkthrough.

## Deploy to Vercel

Import this repository as a new Vercel project. The committed `vercel.json` selects the Vercel-compatible Nitro build and emits Vercel's Build Output API bundle automatically. No build setting needs to be entered manually.

After the first production deployment succeeds, add `corepm.raziiabraham.com` under **Project Settings → Domains**. At the DNS provider for `raziiabraham.com`, create the exact CNAME record Vercel displays for the `corepm` subdomain.
